# Web Access Tips — retired

**This file is retired (2026-10-31).** It used to hold field notes for reaching the web through the owner's older gateway connectors. Those notes are out of date, and nothing here replaces them, because the method now lives where it is always current:

- **Use the owner's Web Access Gateway connector** for all web work. Recognise it by its five tools, `search`, `read`, `browse`, `sign_in` and `status`, never by its name, since names vary.
- **Its tool descriptions say how to use it, and every reply says what happened and what to do next.** When a reply carries a `next`, follow it over anything remembered, including anything you read here before.
- **The owner's own instructions** (his account's Instructions box, or the instructions file on his computer) hold the standing rules: be thorough, never handle his passwords, and hand him a live view when a site needs his sign-in.

If your instructions still say to read this file when the owner says "refresh web access", that line is out of date: re-read your instructions and the gateway's tool descriptions instead, and carry on.

This file contains no secrets, ever.
